📋 Document 1: Complete System Specification

Purpose

Provides complete technical architecture for the WizLingo platform, including technology stack, system design, database schema, API endpoints, and implementation roadmap.

Key Sections

  • Technology Stack: Next.js, Prisma, PostgreSQL, Claude API, Whisper API
  • Architecture Diagram: Client → Frontend → API Layer → Services → Databases
  • Core Services: Content Generation, Answer Validation, Assessment, Progression
  • Authentication: B2B (School) and B2C (Individual) flows
  • Lesson Workflow: End-to-end student learning journey
  • Database Schema: 15+ models for complete data structure
  • API Specifications: 10+ endpoints with request/response examples
  • Frontend Architecture: Component structure, state management, pages
  • Implementation Roadmap: 7 phases over 26 weeks

Audience

Technology team, product managers, system architects, stakeholders evaluating technical feasibility.

📚 Document 2: Curriculum Framework - Detailed Edition

Purpose

Provides comprehensive framework for AI content generation and consultant review. This is the bridge between what the curriculum says to teach and how content gets created and quality-assured.

Key Sections

  • Curriculum Philosophy: CLT, thematic organization, scaffolding, skill integration
  • Age-Grade-CEFR Mapping: Proficiency levels aligned to ages and grades
  • Detailed Learning Objectives: Bloom's taxonomy applied to each skill
  • Vocabulary Framework: Tier 1/2/3 vocabulary with progression
  • Grammar Scope & Sequence: 6 phases from Pre-A1 to B2+
  • Content Specifications: JSON specs for all 5 content types (Vocabulary, Reading, Speaking, Writing, Listening)
  • Assessment Rubrics: 4 levels for each skill area
  • Quality Assurance Checklist: Comprehensive review criteria
  • Consultant Review Template: Professional form for content evaluation
  • Implementation Guidelines: For AI generators and consultants

Audience

AI content generators, curriculum consultants, quality assurance team, content reviewers.

📖 Document 3: Comprehensive K-12 Curriculum

Purpose

The definitive K-12 curriculum document representing international expert consensus on language learning. This is WizLingo's core intellectual property and competitive advantage.

Key Sections

  • Vision & Principles: Convergence of 5 research traditions
  • Science of Reading: 5 components (phonological awareness, phonics, fluency, vocabulary, comprehension)
  • CEFR Integration: Pre-A1 to B2+ proficiency levels
  • Montessori Principles: Child-centered, sensitive periods, scaffolding
  • 5 Learning Pillars: Sound Foundation → Communication → Mastery
  • 20-Level Architecture: Progressive levels from ages 3-18
  • Grade Band Curricula: PreK through Grade 12 with detailed weekly rhythms
  • Special Populations: Struggling readers, advanced learners, ELL support
  • Professional Development: 12-module teacher training
  • Sustainability: Future-proofing and continuous improvement

Audience

All stakeholders. This is the foundation document that informs all other decisions.

🔗 How These Documents Integrate

Workflow

Step 1: Curriculum Framework (Document 3)
Defines WHAT content should be created for each level

Step 2: Detailed Framework (Document 2)
Specifies HOW content should be created and reviewed

Step 3: Complete Specification (Document 1)
Describes the SYSTEM that delivers content to learners

Interdependencies

  • Curriculum → Framework: Vocabulary lists, grammar scope, content types flow from curriculum to generation framework
  • Framework → Specification: Content specifications inform API design and database schema
  • Specification → Curriculum: System capabilities (adaptive AI, assessment) are reflected in curriculum design
