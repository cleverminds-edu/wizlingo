### Available Endpoints

#### 1. **Vocabulary Set Generator**
```bash
POST /api/generate/vocabulary-set

Request:
{
  "theme": "Animals",
  "grade": "Grade1",
  "difficulty_level": 4,
  "word_count": 15
}

Response: 15 vocabulary words with:
- Pronunciation guides
- Definitions
- Example sentences
- Word families (synonyms, antonyms)
- Usage frequency
```

#### 2. **Reading Passage Generator**
```bash
POST /api/generate/reading-passage

Request:
{
  "theme": "Family",
  "grade": "Grade1",
  "difficulty_level": 4,
  "length": "medium",
  "topics_focus": ["vocabulary", "comprehension"]
}

Response: Reading passage with:
- Title and story (100-200 words)
- Comprehension questions (3-5)
- Vocabulary list
- Word count & reading time
- Moral lesson & cultural elements
```

#### 3. **Speaking Topic Generator**
```bash
POST /api/generate/speaking-topic

Request:
{
  "theme": "School Day",
  "grade": "Grade1",
  "difficulty_level": 4,
  "scenario_type": "dialogue"
}

Response: Speaking activity with:
- Scenario setup & context
- Conversation starters
- Example dialogue
- Assessment rubric
- Extension activities
```

#### 4. **Writing Prompt Generator**
```bash
POST /api/generate/writing-prompt

Request:
{
  "theme": "My Favorite Food",
  "grade": "Grade1",
  "difficulty_level": 4,
  "writing_type": "descriptive"
}

Response: Writing task with:
- Clear prompt text
- Planning guide
- Sentence starters
- Rubric with evaluation criteria
- Sample response & common mistakes
```

#### 5. **Listening Story Generator**
```bash
POST /api/generate/listening-story

Request:
{
  "theme": "Adventures",
  "grade": "Grade1",
  "difficulty_level": 4,
  "duration_seconds": 120
}

Response: Audio script with:
- Complete script (narrator + characters)
- Sound effect suggestions
- Production notes
- Comprehension questions
- Discussion questions
```

#### 6. **Demo Endpoint** (No API Key Needed)
```bash
POST /api/generate/demo

Request:
{
  "theme": "Who Am I",
  "grade": "Grade1",
  "difficulty_level": 4,
  "content_type": "vocabulary"  # or reading, speaking, writing, listening
}

Response: Sample content structure (for testing UI)
```

## Phase 2: Setting Up Real Content Generation

### Step 1: Get Anthropic API Key

1. Go to https://console.anthropic.com
2. Create account or sign in
3. Navigate to API Keys
4. Generate new API key
5. Copy and save securely

### Step 2: Configure Environment Variables

Create/update `.env.local`:
```bash
ANTHROPIC_API_KEY=sk-ant-your-api-key-here
```

### Step 3: Test the API

Test a real generation:
```bash
curl -X POST http://localhost:5001/api/generate/vocabulary-set \
  -H "Content-Type: application/json" \
  -d '{
    "theme": "Animals",
    "grade": "Grade1",
    "difficulty_level": 4,
    "word_count": 10
  }'
```

Expected response: Real vocabulary words generated by Claude!

## Troubleshooting

### API Error: "Could not resolve authentication method"
**Solution**: Make sure ANTHROPIC_API_KEY is set in .env.local

### Generation is slow
**Normal**: Claude API calls take 10-30 seconds per piece
**Tip**: Run generation during off-peak hours

### Content quality issues
**Solutions**:
- Adjust `difficulty_level` parameter
- Modify `topics_focus` array
- Tweak prompt templates in content-generator.ts
- Re-generate individual items

### Database errors when storing
- Ensure Prisma migrations are up to date
- Check database connection
- Verify schema has LessonContent table

## Advanced Usage

### Generate Custom Theme
```bash
curl -X POST http://localhost:5001/api/generate/vocabulary-set \
  -H "Content-Type: application/json" \
  -d '{
    "theme": "Technology",
    "grade": "Grade5",
    "difficulty_level": 10,
    "word_count": 20,
    "vocabulary_types": ["nouns", "verbs"],
    "include_word_families": true
  }'
```

### Batch Generate Multiple Grades
Update `scripts/generate-grade-1-curriculum.ts` to include:
- Grade 2
- Grade 3
- etc.

Then run `npm run generate:grade-all`

### Store Generated Content
Create API endpoint: `/api/admin/store-generated-content`
- Parse response
- Create Curriculum Unit
- Store Lessons
- Store LessonContent
