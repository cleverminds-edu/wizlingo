
## Test 1: Happy Path - Successful Session Start

**Request:**
```bash
curl -X POST http://localhost:3000/api/lesson/session/start \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "lessonId": "'"$LESSON_ID"'"
  }'
```

**Expected Response (201 Created):**
```json
{
  "sessionId": "session_789",
  "lessonId": "lesson_001",
  "studentId": "student_123",
  "lesson": {
    "id": "lesson_001",
    "unitId": "unit_123",
    "title": "Reading Comprehension: The Adventure",
    "description": "Read a passage and answer questions",
    "estimatedMinutes": 15,
    "contents": [
      {
        "id": "content_1",
        "type": "LESSON",
        "sequence": 1,
        "title": "Introduction",
        "content": {
          "text": "Welcome to the lesson..."
        },
        "mediaUrl": null
      },
      {
        "id": "content_2",
        "type": "EXERCISE",
        "sequence": 2,
        "title": "Practice Questions",
        "content": {
          "passage": "Once upon a time...",
          "questions": [
            {
              "id": "q1",
              "type": "multiple_choice",
              "question": "What is the main character?",
              "options": {
                "a": "John",
                "b": "Sarah",
                "c": "Michael",
                "d": "Emma"
              }
            }
          ]
        },
        "mediaUrl": null
      }
    ]
  },
  "timing": {
    "startedAt": "2026-06-30T10:00:00Z",
    "expiresAt": "2026-06-30T10:30:00Z"
  }
}
```

**Check:**
- ✅ Status code is 201
- ✅ `sessionId` is present
- ✅ `lesson.contents` includes all content blocks
- ✅ Response includes `timing` with `startedAt` and `expiresAt`
- ✅ Lesson database has `LessonSession` record created

## Test 6: Duplicate Session - Returns 409

**Prerequisite:** Run Test 1 first, then immediately run this test

**Request:**
```bash
# Using same TOKEN and LESSON_ID from previous test
curl -X POST http://localhost:3000/api/lesson/session/start \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "lessonId": "'"$LESSON_ID"'"
  }'
```

**Expected Response (409 Conflict):**
```json
{
  "error": "Conflict: Active session already exists for this lesson",
  "sessionId": "session_789"
}
```

**Check:**
- ✅ Status code is 409
- ✅ Existing `sessionId` is returned
- ✅ Student can't start duplicate sessions

## Debugging Tips

**If tests fail:**

1. **401 errors:** Check token is valid and not expired
2. **404 errors:** Verify lessonId exists in database
3. **409 errors:** Complete or delete the previous session
4. **500 errors:** Check server logs: `tail -f logs/app.log`
5. **Response time slow:** Check database indexes on lessonId
