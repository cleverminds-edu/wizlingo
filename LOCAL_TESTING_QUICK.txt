🚀 QUICK START (5 minutes to running)
═══════════════════════════════════════════════════════════════════════════════

1. Setup Database:
   npx prisma migrate deploy
   npx prisma db seed

2. Start App:
   npm run dev
   (Check: "Server running on port 3000")

3. Run Tests:
   npm test
   (Check: "75+ tests pass")

4. Create Test Account:
   curl -X POST http://localhost:3000/api/auth/signup \
     -H "Content-Type: application/json" \
     -d '{
       "name": "Test User",
       "email": "test@local.test",
       "password": "TestPass123!",
       "gradeCategory": "GR_1_3"
     }'

5. Start Lesson:
   curl -X POST http://localhost:3000/api/lesson/session/start \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"lessonId": "lesson_001"}'

✅ TESTING CHECKLIST
═══════════════════════════════════════════════════════════════════════════════

SETUP PHASE (15 min):
  □ Database migrated
  □ Test data seeded
  □ App starts (npm run dev)
  □ Health endpoint works (curl http://localhost:3000/api/health)
  □ Unit tests pass (npm test)

AUTH PHASE (10 min):
  □ Signup works (201 Created)
  □ Login works (200 OK)
  □ Get token from response
  □ Protected endpoints require token (401 without)

LESSON START (T1.2) (10 min):
  □ Start lesson with token (201 Created)
  □ Response includes sessionId, lesson, timing
  □ Contents ordered by sequence
  □ Invalid lesson returns 404
  □ No token returns 401

LESSON SUBMIT (T1.3 + T1.4) (15 min):
  □ Submit all correct (score=100, xp=100)
  □ Submit partial (score=66, xp=50)
  □ Submit wrong (score=0, xp=50)
  □ Invalid answers return 400
  □ Duplicate submit returns 409

RESULTS DISPLAY (T1.6) (10 min):
  □ Results page loads
  □ Shows score percentage
  □ Shows XP earned
  □ Shows feedback messages
  □ Can expand question details

DATABASE (10 min):
  □ LessonSession created
  □ Responses saved
  □ Student XP updated
  □ Data persists across requests

PERFORMANCE (10 min):
  □ Lesson start < 500ms
  □ Lesson submit < 500ms
  □ No console errors
  □ No memory issues

SECURITY (10 min):
  □ Invalid token rejected (401)
  □ Empty input rejected (400)
  □ Password hashed (not plain text)
  □ Session isolation works

🧪 KEY TESTS
═══════════════════════════════════════════════════════════════════════════════

HAPPY PATH:
  1. Create account → 201
  2. Start lesson → 201 with sessionId
  3. Submit answers → 200 with score
  4. View results → Page loads with feedback
  5. Check DB → All data saved

ERROR CASES:
  • No token → 401 Unauthorized
  • Invalid lesson → 404 Not Found
  • Duplicate session → 409 Conflict
  • Invalid answer → 400 Bad Request
  • Duplicate submit → 409 Conflict

PERFORMANCE:
  • Lesson start < 500ms
  • Lesson submit < 500ms
  • Database queries < 100ms
