## EXECUTIVE SUMMARY

WizLingo is currently a strong **Reading + Speaking** platform with:
- 78+ API endpoints supporting dual authentication (B2B schools + B2C individuals)
- Adaptive learning (auto-level up/down based on performance)
- Gamification (5 badge types, multiple leaderboards, social sharing)
- Multi-role dashboards (student, teacher, admin)

**Strategic Goal**: Transform into India's **#1 AI-Powered LSRW English Learning Ecosystem** (K-12 + lifelong) by adding:

1. **Writing** (essays, paragraphs, grammar exercises)
2. **Listening** (comprehension, audio passages, pronunciation)
3. **Curriculum Architecture** (6 progressive levels, CEFR/Cambridge/NEP2020 aligned)
4. **B2B School Management** (principal oversight, teacher tools, student bulk enrollment)
5. **Formal Assessment** (rubrics, diagnostics, skill tracking)
6. **Role Expansion** (Principal, Academic Incharge, GlobalManager, Parent)
7. **LSRW Integration** (unified dashboards, cross-skill insights)

**Timeline**: 8 weeks to MVP (full LSRW + B2B management)  
**Team**: 8-10 full-stack developers, 1 curriculum specialist, 1 QA engineer

// Pseudo-code
function determineNextActivity(sessionProgress, studentLevel) {
  const activities = ["LISTENING", "SPEAKING", "READING", "WRITING"];
  
  // If student weak at writing, add extra writing this week
  if (studentLevel.writingScore < 60) {
    return randomize([WRITING, READING, SPEAKING, LISTENING]);
  }
  
  // If student strong at reading, add harder reading
  if (studentLevel.readingScore > 85 && !hasLeveledUpRecently("READING")) {
    const recommendedLevel = studentLevel.reading + 1;
    return ReadingActivity(level: recommendedLevel);
  }
  
  // Standard LSRW rotation
  return rotateActivities(activities);
}

function checkLevelUpTrigger(skill, lastNSessions) {
  // Skill-specific level-up (not global)
  const last5Sessions = db.query(`
    SELECT score FROM ActivitySubmission 
    WHERE studentId = ? AND skillType = ?
    ORDER BY createdAt DESC LIMIT 5
  `);
  
  if (last5Sessions.length === 5 && last5Sessions.every(s => s.score >= 85)) {
    return { levelUp: true, newLevel: studentLevel[skill] + 1 };
  }
  return { levelUp: false };
}
```

## PHASE 5: CURRICULUM SEEDING (Week 3-4)

### 6-Level Curriculum Structure

**Level 1: Nursery-UKG (Ages 4-5)**
- CEFR: A0 (Pre-A1)
- Cambridge: YLE Starters (optional)
- Outcomes: Letter recognition → CVC words → basic speaking
- Sample lessons:
  - Lesson 1.1: "Alphabet Song" (Listening + Speaking)
  - Lesson 1.2: "Trace & Say Letters" (Reading + Writing)
  - Lesson 1.3: "CVC Word Builder" (All 4 skills)

**Level 2: Grades 1-3 (Ages 6-9)**
- CEFR: A1
- Cambridge: YLE Movers (optional)
- Outcomes: Independent reading → dictation → guided sentences
- Grammar scope: Nouns, verbs, present simple, questions
- Vocabulary: 500-800 words

**Level 3: Grades 4-7 (Ages 10-13)**
- CEFR: A2
- Cambridge: YLE Flyers (optional)
- Outcomes: Reading comprehension → paragraph writing → fluent speaking
- Grammar scope: Past tense, have/has, modals (can, should)
- Vocabulary: 1200-1500 words

**Level 4: Grades 8-10 (Ages 14-16)**
- CEFR: B1
- Cambridge: PET (Preliminary English Test)
- Outcomes: Essay writing → formal letters → presentations
- Grammar scope: Complex sentences, passive voice, conditionals
- Vocabulary: 2000-3000 words (academic)

**Level 5: Grades 11-12 (Ages 17-18)**
- CEFR: B2-C1
- Cambridge: FCE, CAE (optional)
- Outcomes: Professional communication → analytical essays → debate
- Vocabulary: 3500+ words (domain-specific)

**Level 6: Lifelong Learning (Adult)**
- IELTS/TOEFL prep
- Business English
- Specialized domains (Tech, Medical, Legal)

def evaluate_pronunciation(audio_file_path: str, reference_text: str):
  """Use Whisper to transcribe and evaluate pronunciation"""
  
  # Step 1: Transcribe student's audio
  with open(audio_file_path, "rb") as audio:
    transcript = openai.Audio.transcribe(
      model="whisper-1",
      file=audio,
      language="en"
    )
  
  # Step 2: Compare with reference
  similarity_score = compare_text_similarity(
    transcript.text,
    reference_text
  )  # 0-100
  
  # Step 3: Calculate pronunciation score
  pronunciation_score = {
    "accuracy": similarity_score,  # How close to reference?
    "fluency": calculate_fluency(audio_file_path),  # Speech rate, pauses
    "clarity": calculate_clarity(audio_file_path),  # Pronunciation clarity
    "overall": (accuracy + fluency + clarity) / 3
  }
  
  return pronunciation_score
```

from google.cloud import texttospeech

def generate_audio_for_listening(text: str, voice_id: str = "en-US-Neural2-A"):
  """Generate audio file for listening comprehension"""
  
  client = texttospeech.TextToSpeechClient()
  synthesis_input = texttospeech.SynthesisInput(text=text)
  
  voice = texttospeech.VoiceSelectionParams(
    language_code="en-US",
    name=voice_id  # Different voices for variety
  )
  
  audio_config = texttospeech.AudioConfig(
    audio_encoding=texttospeech.AudioEncoding.MP3,
    speaking_rate=1.0  # Can adjust for level (0.8 for slow, 1.2 for faster)
  )
  
  response = client.synthesize_speech(
    input=synthesis_input, voice=voice, audio_config=audio_config
  )
  
  # Save to S3
  s3_key = f"listening/{hashlib.md5(text).hexdigest()}.mp3"
  s3_client.put_object(Bucket="wizlingo-audio", Key=s3_key, Body=response.audio_content)
  
  return f"https://s3.amazonaws.com/wizlingo-audio/{s3_key}"
